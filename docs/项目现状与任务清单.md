## 六、需要立刻和伙伴对齐的 4 件事

1. **架构路线**（E1）：SSR 还是 REST？这决定你们后面所有代码的形态。
2. **schema 用哪套**（B3）：`database/01-schema.sql` 那 7 张表设计得很完整（含 CHECK 约束、快照字段、乐观锁），建议以它为准，废弃 `sql/schema.sql`。
3. **接口契约**（E7）：至少先定 URL 前缀、统一响应体 `{code,msg,data}`、错误码表、分页字段。
4. **模块边界**（E8）：购物车/订单要读商品价格和库存，谁提供 `ProductService`？分类归谁？
